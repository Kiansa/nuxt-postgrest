```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-postgrest'],
  postgrest: {
    url: 'http://localhost:3001',
    key: '',
    schema: 'public',
    auth: {
      provider: undefined, // auto-detected
      tokenKey: 'postgrest_token',
    },
    types: {
      path: '~~/shared/types/database.types.ts',
      generate: false,
      schemas: ['public'],
    },
  },
})
```

## Options

| Option | Default | Description |
| --- | --- | --- |
| `url` | `''` | PostgREST API URL. |
| `key` | `''` | Public anon JWT sent when no user token is available. Empty means no `Authorization` header, so PostgREST uses its `db-anon-role`. |
| `schema` | `'public'` | Default Postgres schema for every client. |
| `auth.provider` | auto | `'nuxt-auth-utils'` or `'none'`. Detected from your installed modules. |
| `auth.tokenKey` | `'postgrest_token'` | Session field that holds the user's PostgREST JWT. |
| `types.path` | `'~~/shared/types/database.types.ts'` | Generated `Database` type used to type every client. |
| `types.generate` | `false` | Regenerate `types.path` with the Supabase CLI on `nuxt dev` / `nuxt prepare`. |
| `types.schemas` | `['public']` | Schemas included in generated types. |

## Environment variables

Runtime values can be overridden per environment without rebuilding:

| Variable | Scope | Maps to |
| --- | --- | --- |
| `NUXT_PUBLIC_POSTGREST_URL` | Public | `url` |
| `NUXT_PUBLIC_POSTGREST_KEY` | Public | `key` |
| `NUXT_POSTGREST_SECRET_KEY` | Server only | Secret JWT for `usePostgrestAdmin()` |
| `NUXT_POSTGREST_DB_URI` | Build tooling | Database URL for type generation |

::warning
`NUXT_POSTGREST_SECRET_KEY` usually maps to a role that bypasses RLS. It is never exposed to the client, but keep it out of `nuxt.config.ts` and version control.
::
