title: Coming from Supabase
description: Map @nuxtjs/supabase patterns to Nuxt PostgREST.

  icon: i-lucide-arrow-right-left
---

Both modules use the same `postgrest-js` query builder and the same generated types, so queries move over unchanged. What differs is everything around the database.

| `@nuxtjs/supabase` | Nuxt PostgREST |
| --- | --- |
| `useSupabaseClient()` | `usePostgrest()` |
| `serverSupabaseClient(event)` | `usePostgrestUser(event)` |
| `serverSupabaseServiceRole(event)` | `usePostgrestAdmin()` |
| `supabase.from('x')` | `postgrest.from('x')` (identical API) |
| Supabase Auth | Your auth, e.g. nuxt-auth-utils. See [Authentication](/guide/authentication) |
| Storage, Realtime | Not included |

Your existing `database.types.ts` works as is. Point `types.path` at it.
